# OpenShop 多语言文字工具阶段 4 验证报告

## 验证范围

- 每个“图文分层”节点按 `projectId + canvasType + canvasId + nodeId` 独立保存文字工具数据。
- OpenShop 复用 HstarA 全局 API 配置，不保存第二套 Base URL、API Key 或 CLI 凭据。
- “文字提取”和“去除文字”是两个独立工具，分别保存 API/模型偏好并执行不同任务。
- 文字提取覆盖中文、英文、中英混排、低置信度校对和确认后创建可编辑 Fabric 文字图层。
- 去除文字覆盖整层和选区模式，成功后创建新的像素图层，原始图层保持不变。
- 普通画布、智能画布、多节点、节点克隆、项目重开、任务恢复、取消和迟到响应均纳入验证。

## API 与安全

- `GET /api/openshop/ai/catalog` 仅返回公开能力字段，不返回密钥、Authorization 或私有连接信息。
- 实时模型发现继续调用 HstarA 现有 `/api/providers/{id}/fetch-models`，项目仅保存 `apiConfigId + modelId + toolId`。
- 项目指定的 API 或模型被删除后显示“配置不可用”，不会静默切换到其他模型。
- 文字提取复用 HstarA 视觉/大语言模型执行通道；去除文字复用图片编辑执行通道。
- 项目清单递归拒绝密钥字段和内联 `data:image/`，任务记录最多保存 `100` 条。
- 最终普通/智能画布项目 JSON 未发现 `apiKey`、`authorization`、`data:image/` 或 `blob:` 长期数据。

## 文字提取

- 后端只接受带可靠四点坐标或边界框的结构化 OCR；纯文本响应、越界坐标、空文字块和无位置结果均失败。
- E2E 一次返回中文、英文和中英混排三类文字块，低于 `0.7` 的置信度在校对区明确标记。
- 用户确认前不改动画布；确认后新建“提取文字”图层并创建可编辑 `IText` 对象。
- 文字对象恢复坐标、字号、字体候选、颜色、字重、样式、对齐、旋转、语言和置信度元数据。
- 重开项目时，已完成但未应用的 OCR 任务恢复到校对状态，并继续使用原始源图资源预览。

## 去除文字

- 整层去字和选区去字不调用 OCR，也不删除或替换原图层。
- 选区模式上传与文档同尺寸的 PNG 蒙版；成功结果作为新的“去除文字”像素图层叠加。
- 失败、取消或客户端解码失败不创建图层；解码失败保留可重试的成功任务记录。
- 取消后的迟到成功响应被会话代际检查丢弃，不会补建图层或覆盖 `cancelled` 状态。
- 恢复任务时若输出资源已存在于图层，只补记 `appliedAt`，不会重复插入同一结果。

## 隔离与恢复

- 同一普通画布中的节点 A 和 B 分别保存 OCR 与去字任务、偏好、字体和输出，重开后互不出现对方数据。
- 智能画布使用同一套项目和任务协议，并保持 `canvasType: smart` 所有权。
- 未完成任务在项目加载后继续轮询；服务重启导致后台任务表丢失时，记录被明确标记为失败，不会永久停留在运行中。
- 克隆节点保留图层、字体引用和 API 偏好，但清空源节点的 `aiTaskRecords`，避免克隆后续接或应用旧节点任务。
- 删除项目会取消该项目仍在运行的任务，不影响同画布其他节点。

## 视觉与 4K

- 检查视口：`1440 x 1000`、`1920 x 1080`、`430 x 932`。
- 桌面端文字工具面板与 OpenShop 主图层面板并排，无横向溢出、按钮截断或文字重叠。
- 移动端面板底边固定在 `48 px` 底部工具栏上方，宽度不超过 iframe 视口，全部按钮文字可见。
- 4K 文字工具场景：`4096 x 4096` 文档、`20` 个 OCR 块、`20` 个文字对象、一个选区蒙版任务和一个独立去字图层。
- 4K 场景保留 `1` 个源图层，两个 AI 任务均为 `succeeded` 且已应用，缩略像素采样和 PNG 预览均非空。

## 后续范围

- 当前字体功能负责检测可用/缺失状态和用户明确替换，不包含联网下载或安装系统字体。
- 当前 OCR 校对支持逐条文字编辑，不包含直接拖拽四点框、段落重排和高级排版拟合。
- 当前去字覆盖整层和已有选区，不包含阶段 5 的任意画笔蒙版、通用局部生成式填充和多候选结果管理。
- PSD 导出继续使用 OpenShop 现有能力，本阶段未增加 Photoshop 往返兼容性承诺。
- 真实 OCR 和图片编辑质量取决于用户选择的全局 API、模型能力及上游响应质量。
