# OpenShop 图层限定栅格工具与字型归类设计

## 背景

当前画笔和橡皮擦依赖 Fabric 自由绘制路径。橡皮擦路径使用画布级
`destination-out`，因此会穿透当前图层并擦除所有更低图层；两种工具又会为每次笔画新增可选
对象，造成轨迹可移动、擦除位置跟随轨迹而非图层、对象持续累积和高分辨率画布卡顿。

仿制图章、修复画笔和润饰工具会从整张画布回退查找图像，并在操作结束后删除旧对象、把新图像
追加到画布顶部。这会破坏活动图层边界和全局堆叠顺序。字体目录则把 Windows 返回的每个字面名称
当成独立字体家族，导致 `DengXian` 和 `DengXian Light` 无法在“字体/字型”两级控件中归类。
对象移动已支持画板边界吸附，但对象缩放事件尚未接入吸附引擎。

## 目标

1. 画笔、橡皮擦和仿制图章只修改当前主选图层中的栅格图像。
2. 拖动期间原位更新像素，松开时只提交一次历史记录，不新增可移动轨迹对象。
3. 切换工具、丢失指针或重复操作时只有一个有效栅格会话，不遗留全局监听器。
4. 修复画笔、润饰、填充和删除选区等栅格命令不得回退到其他图层的图像。
5. 图像对象原位保留在原画布索引；必须替换时也保留图层、变换、业务元数据和堆叠位置。
6. 本机字体按家族归类，具体本机字面在“字型”中选择；未主动选择时使用家族常规字型。
7. 对象缩放时，左、右、上、下边界以及中心线均可实时吸附画板。

## 非目标

- 不把文字、形状等可编辑矢量对象静默栅格化。
- 不改变 HstarA 图文分层项目协议、后台任务协议或导出尺寸。
- 不加入新的吸附开关，画板几何吸附继续默认开启。
- 不在本轮重写选区、钢笔、裁切或 AI 工具的业务算法。

## 活动图层栅格会话

新增独立控制器管理画笔、橡皮擦和仿制图章。控制器只接受编辑器当前
`activeLayerIdx` 对应的可见、未锁定图层，并从该图层选择活动图像或最上方图像。不能从画布全局
查找候选图像。

开始笔画时，控制器把目标图像元素复制到可编辑的内存画布，并通过 `setElement` 让原 Fabric 图像
对象继续承载内容。对象身份、变换、图层数组位置和画布堆叠索引均不变化。指针从文档坐标通过目标
对象逆矩阵转换为源像素坐标。

- 画笔使用 `source-over` 和当前前景色、透明度。
- 橡皮擦使用目标内存画布内部的 `destination-out`，只影响这一个图像。
- 仿制图章在 `Alt+单击` 时记录文档源点，开始绘制时冻结目标图像快照，后续印章始终从冻结快照
  取样，避免递归复制刚写入的像素。

移动事件只绘制新线段并通过动画帧请求画布重绘。松开、窗口指针释放或工具切换只允许一个结束
路径：结束成功时保存一次历史，取消时恢复开始前的元素。控制器不注册每笔一次的
`document.mouseup` 监听器。

当活动图层为空或只含矢量对象时，画笔和橡皮擦显示明确提示，不静默写入其他图层。以后可单独增加
“新建像素图层/栅格化图层”，但不属于本轮范围。

## 图层边界与通用栅格命令

主编辑器提供统一的 `_activeLayerRasterTarget` 查询。仿制图章、修复画笔、减淡、加深、海绵、涂抹、
填充和删除选区使用它获取目标。目标不在活动图层时命令直接拒绝。

仍需异步生成新图像的命令通过统一原位替换函数提交。替换函数复制 `hstarLayerId`、素材绑定、局部
重绘锚点和可见/交互属性，并使用原画布索引插入，不能简单 `canvas.add` 到顶部。

## 字体家族与字型

字体服务在规范化 Windows 字面时识别常见字型后缀（Thin、Light、Medium、Semibold、Bold、Black、
Italic、Oblique 等），并结合权重和斜体标记生成家族名称。每个字型保留真实 `family`，用于浏览器
实际渲染。例如：

- 家族：`DengXian`
- 字型一：`Regular`，真实字面 `DengXian`
- 字型二：`Light`，真实字面 `DengXian Light`

前端字体下拉只列家族。选择家族时默认选择最接近 400、非斜体的字型；“字型”下拉显示该家族的
所有真实字面。切换字型同时写入真实 `fontFamily`、`fontWeight` 和 `fontStyle`。已有文本使用 Light
字面时，字体控件仍显示家族 DengXian，字型控件显示 Light。

## 缩放吸附

吸附引擎新增纯函数 `resolveScale`，按 Fabric 当前控制点决定可移动边：左侧控制点只检查左边，右侧
只检查右边，上下同理；角控制点可同时处理两个轴。容差继续按屏幕像素换算为文档坐标。

编辑器监听 `object:scaling`。引擎返回目标边界矩形后，编辑器调整 `scaleX/scaleY`，重新读取实际
边界并补偿 `left/top`，确保缩放后的可见边界精确落在画板边界。旋转或倾斜对象暂不参与缩放吸附，
避免轴对齐矩形造成意外变形。

## 错误处理

- 活动图层锁定、隐藏、没有栅格图像或目标元素不可绘制时，不启动会话且不写历史。
- 跨域或损坏图像无法复制到内存画布时，恢复原对象并显示错误。
- 新工具开始前取消未完成会话，避免两个工具并发修改同一目标。
- 字型归类无法识别时保留原字体名为独立家族，不猜测或丢弃本机字体。
- 缩放吸附只接受有限正数尺寸；异常几何保持 Fabric 原始变换。

## 测试策略

1. 单元测试证明橡皮擦只修改活动图层目标、画笔/橡皮擦不创建 Fabric 路径、每笔只提交一次。
2. 单元测试证明仿制图章不会触发复制命令、不会改变对象数量和堆叠索引。
3. 多图层测试证明修复和润饰工具拒绝修改非活动图层。
4. Python 与前端测试覆盖等线/等线 Light、雅黑/雅黑 Light 的家族归类和真实字型应用。
5. 纯几何和编辑器测试分别覆盖八个缩放控制点及四边吸附。
6. Playwright 在独立 OpenShop 页面完成多图层擦除、画笔、图章和缩放回归，不创建 HstarA 测试画布。

## 验收标准

- 多图层擦除只改变当前图层，隐藏当前图层后下层内容完整。
- 擦除或绘画后对象数量不增加，轨迹不可独立选中或移动；移动目标图层时像素结果随图层移动。
- 连续 50 次短笔画不会创建 50 个 Fabric 路径或全局释放监听器。
- 仿制图章前后图层顺序和对象数不变。
- 等线类字体只出现一个家族，字型下拉可选常规和 Light。
- 缩放对象靠近画板任一边时可吸附，继续拖动超过容差后可解除吸附。
