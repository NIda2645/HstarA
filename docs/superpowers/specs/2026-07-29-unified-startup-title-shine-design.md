# Hstar 启动标题整体扫光设计

## 目标

将启动画面中的三颗星标和 `Hstar 正在启动中` 文字视为一个完整视觉对象。每次扫光从最左侧星标外进入，按空间顺序穿过全部星标和文字，再从文字最右侧离开，全程只有一条连续高光带。

## 视觉与动画

- 保持现有三颗星标造型、标题尺寸、居中位置和元素间距。
- 保持 `#b5b5b5` 灰金属底色与 `#ffffff` 纯白高光。
- 保持每轮 `2s` 的线性循环节奏。
- 高光方向固定为从左到右，星标与文字不再拥有各自的动画或独立相位。
- 开启系统“减少动画”时停止扫光，整组保持稳定可读的灰白静态效果。

## 实现结构

`desktop/Hstar.Desktop/Assets/startup/index.html` 将使用一个 SVG 表达完整标题组：星标路径与文字共同组成同一个裁剪轮廓。轮廓内先绘制固定灰色底层，再绘制一个横跨整组宽度的高光矩形。

`desktop/Hstar.Desktop/Assets/startup/startup.css` 只动画这一个高光矩形。矩形从整组左侧外移动到右侧外，因此可见高光必然依次经过星标、间隙后的文字，不需要 JavaScript 尺寸测量或两组动画延迟换算。

外层 `role="status"` 和中文 `aria-label` 保持不变，视觉 SVG 继续对辅助技术隐藏。

## 范围

本次不修改 Lightfall 背景、顶部玻璃工具栏、启动时长、后端就绪逻辑、失败控件或桌面壳层。不引入新依赖，也不改动用户其他未提交修改。

- 更新 `StartupAssetTests`，确认星标与文字位于同一裁剪轮廓，且只存在一个 `2s` 整体扫光动画。
- 运行桌面端相关自动测试，确认本地资源、CSP 和减少动画约束仍然通过。
- 刷新现有本地预览，检查高光从星标最左端连续运行到文字最右端，标题保持水平和垂直居中。
