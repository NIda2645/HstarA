# OpenShop 原位生成式填充与局部重绘设计

## 1. 目标

在 HstarA 的 OpenShop 编辑器中增加两个独立功能：

- `生成式填充`
- `局部重绘`

两个功能直接嵌入 OpenShop 现有选区工作流，不新增独立页面、右侧工具面板或常驻候选区。用户使用 OpenShop 原有矩形选框、套索或像素选区确定范围，随后在画布底部按需出现的轻量操作栏中完成提示词、API、模型、尺寸、质量、参考图和生成数量设置。

阶段 5A 不包含独立的“AI 生成图层”功能，不包含种子设置，不改变阶段 4 已完成的文字提取和去除文字功能。

## 2. 设计原则

- 原位编辑：所有操作发生在现有 OpenShop 编辑界面内。
- 功能独立：生成式填充和局部重绘拥有独立按钮、参数偏好和任务记录。
- 非破坏式：选区外像素不变，生成结果始终创建新图层，不覆盖源图层。
- 快速进入：两个按钮始终可点击，无选区时自动进入选区工具等待框选。
- 后台持续：隐藏 OpenShop 页面只改变界面可见性，不能中断任何任务进程。
- 项目隔离：所有状态、资源、任务和图层按 OpenShop `projectId` 隔离。
- 全局配置：继续复用 HstarA 全局 API 和实时模型能力目录，不保存第二套密钥。

## 3. 组件架构

阶段 5A 不把实现继续堆入 `openshop-text-tools.js`，而是新增独立模块：

- `openshop-generative-tools.js`：两个功能入口、选区状态机、底部操作栏、参数偏好和多图层插入。
- `openshop-reference-manager.js`：主参考实时缩略图、额外选区、图层、本地文件、素材库资源和 @ 映射。
- `openshop-generative-client.js`：能力目录、父子任务创建、持续轮询、取消、恢复和部分成功。
- `openshop-project-adapter.js`：序列化生成工具偏好、参考记录、父子任务和待插入结果。
- 外层 `openshop-host.js`：按 `projectId` 管理可见/隐藏编辑会话，关闭只隐藏会话，节点卡片接收进度和保存状态。
- HstarA 后端：扩展 `openshop_ai.py` 纯契约和任务注册表，`main.py` 执行多参考图片任务与结果规范化，`openshop_projects.py` 负责有界持久化和资源清理。

模块之间只传结构化项目上下文、资源 ID、任务 ID 和公开模型能力。大型图片、蒙版和结果不通过 `postMessage` 传 Base64。

## 4. 功能边界

### 4.1 生成式填充

- 提示词允许为空。
- 空提示词表示根据选区周围内容自动补全、移除或生成内容。
- 固定使用当前可见画面的全图上下文和同尺寸选区蒙版。
- 不显示局部重绘的参考模式胶囊和多参考图管理。

### 4.2 局部重绘

- 必须填写修改要求。
- 提供 `参考选择区域 / 参考全图` 分段胶囊控件。
- 支持主参考实时缩略图、额外选区参考、项目图片图层、本地图片和 HstarA 素材库图片。
- 支持在提示词中通过 `@选区N` 和 `@参考图N` 精确说明每张参考承担的作用。

### 4.3 明确不做

- 不提供种子、固定种子或随机种子控件和存储字段。
- 不提供生成后候选确认页或底部候选条。
- 不把生成式填充和局部重绘合并成单一按钮。
- 不新增独立工作台、弹窗式编辑器或新的 OpenShop 页面。

## 5. 入口与选区状态机

两个按钮放在 OpenShop 选区参数栏附近，并始终可点击。

状态机：

1. `idle`：未进入局部生成功能。
2. `selecting`：点击任一按钮但当前没有有效选区。
3. `ready`：已存在有效选区，底部参数栏展开。
4. `preparing`：冻结任务快照并上传资源。
5. `running`：后台生成、上传结果和写入项目。
6. `partial`：目标数量只有部分生成成功，可补生成剩余数量。
7. `succeeded`、`failed`、`cancelled`：终态。

点击行为：

- 无选区时点击按钮，自动激活上次使用的 OpenShop 选区工具并进入 `selecting`。
- 首次使用默认矩形选框，之后记住矩形选框、套索等上次选择。
- `selecting` 期间底部只显示“请先选择要修改的区域”提示条，不上传图片或创建任务。
- 用户完成有效框选后自动进入 `ready`，提示条原位展开为参数操作栏。
- 已有有效选区时点击按钮，直接进入 `ready`。
- 取消选区后返回 `selecting`，保留当前功能、提示词和尚未提交的参数。
- 关闭底栏才退出当前功能并回到 `idle`。

## 6. 底部操作栏

操作栏位于画布底部中央，按需出现，不能遮挡 OpenShop 底部工具栏或右侧图层面板。

公共控件：

- 当前功能和选区数量。
- 提示词输入框；局部重绘必填，生成式填充可为空。
- HstarA 全局 API / 模型选择。
- 生图尺寸选择。
- 质量选择。
- 生成数量数字步进器。
- 提交、取消和关闭按钮。
- 逐张进度和部分成功状态。

生成数量不是固定的一张或三张。步进器上限跟随所选模型实时能力；模型未声明上限时最多 `8` 张。操作栏不包含种子控件。

移动端操作栏变为位于 `48 px` 底部工具栏上方的抽屉，输入框、缩略图、@ 选择窗口和提交按钮必须保持可见且可滚动。

## 7. 局部重绘参考模式

### 7.1 参考选择区域

- 主参考图为当前选区外接矩形的裁剪图。
- 实时缩略图显示该裁剪区域。
- 适合根据局部人物、物体或纹理做定向变化。
- 生成结果按冻结的选区原坐标回贴。

### 7.2 参考全图

- 主参考图为当前可见图层的完整合成画面。
- 实时缩略图显示全图。
- 请求同时携带完整画面和同尺寸蒙版。
- 适合保持整体光线、构图和环境一致性。

局部重绘默认选择 `参考全图`。选区变化、参考模式切换、可见图层变化、图层内容变化或项目切换时，主参考缩略图实时刷新。任务提交后固定本次主参考资源版本，不受后续画布变化影响。

## 8. 参考缩略图与添加入口

参考缩略图排列在提示词输入框上方左侧，保留 `＋` 按钮。

`＋` 支持：

- 添加当前选区。
- 从当前 OpenShop 项目的图片图层选择。
- 从 HstarA 素材库选择。
- 从本地上传图片。

命名规则固定：

- 选区参考：`选区1`、`选区2`……
- 图片参考：`参考图1`、`参考图2`……
- 提示词引用形式：`@选区1`、`@选区2`、`@参考图1`、`@参考图2`……

主参考图为第一张参考缩略图。额外参考图数量上限跟随模型能力；模型未声明时，选区和图片参考总数最多 `8` 张。

## 9. @ 快捷引用

用户在局部重绘提示词中输入 `@` 时，在光标附近打开轻量快捷窗口。窗口只显示当前操作栏已经添加的全部选区和图片，包括：

- 缩略图。
- 固定引用名称。
- 来源类型：主参考、选区、图层、素材库或本地文件。

点击后把引用标记插入提示词。所有已添加参考图始终随任务发送，`@` 不控制是否发送，只负责把提示词中的语义角色映射到具体资源。

## 10. 任务快照与请求

任务提交时冻结：

- `projectId` 和画布、节点所有权。
- 功能 ID：`generative-fill` 或 `local-redraw`。
- 文档宽高和任务创建时的图层版本。
- 选区蒙版、外接矩形、羽化和坐标。
- 源图层 ID、源图层索引和当前可见合成版本。
- 提示词、模型、尺寸、质量和目标生成数量。
- 局部重绘的主参考模式。
- 全部参考资源 ID、固定引用名、来源类型、顺序和 @ 映射。

请求和项目记录不得包含 `seed` 字段，不保存 API Key、Authorization、Data URL 或 Blob URL。

后端根据模型能力选择单次批量请求或多个受控并发请求。每个输出具有独立子任务状态和资源 ID，父任务维护目标数量、完成数量、失败数量和取消状态。

## 11. 输出规范化与自动建层

输出必须规范化为带透明通道的局部结果：

- 上游返回完整图片时，后端根据任务蒙版提取目标选区，选区外像素设为透明。
- 上游返回裁剪图时，按冻结的选区外接矩形缩放并回贴，选区外保持透明。
- 输出尺寸、边界和透明像素经过服务端校验，空结果和错位结果不能进入图层树。

目标生成数量为 N 时，成功得到多少张就自动创建多少个默认可见的独立图层：

- `生成式填充 1/N`、`生成式填充 2/N`……
- `局部重绘 1/N`、`局部重绘 2/N`……

图层按生成顺序插入冻结的源图层上方，位置相同，因此画布自然显示最上层结果。系统不自动关闭任何结果图层的眼睛，用户通过现有图层面板自行比较。

每个结果图层记录任务 ID、子任务 ID、提示词、模型、尺寸、质量、功能 ID、主参考模式、参考资源和源图层快照，不记录种子。

## 12. 隐藏页面持续运行

OpenShop 关闭按钮只隐藏全屏页面并返回画布，不能停止会话、轮询、控制器、资源上传、自动建层或自动保存。

- 隐藏 OpenShop iframe、项目会话和前端控制器保持运行。
- 隐藏状态下生图完成后立即接收结果、创建全部图层并保存项目。
- 画布节点卡片实时显示后台进度、完成数量、图层数量和保存状态。
- 再次打开同一节点时复用原来的实时会话，不重新加载项目或恢复任务。
- 打开另一个 OpenShop 节点时，为它创建独立会话；前一个隐藏会话继续运行。
- 隐藏会话只有在全部任务完成、资源写入和自动保存成功后，才可进入空闲回收。
- 主动取消、删除节点、删除画布或退出整个 HstarA 进程才允许终止任务。

关闭 OpenShop 不得调用 `stopSession()`、终止轮询、AbortController 或任务取消接口。

## 13. 部分成功与错误处理

- 请求 N 张只成功 M 张时，立即创建 M 个完整图层并显示 `已完成 M/N`。
- 失败子任务不创建空图层。
- 提供“补生成剩余数量”，沿用冻结的提示词、参考图和参数，但形成新的补生任务记录。
- 主动取消终止未完成子任务；迟到响应不能创建图层或覆盖 `cancelled`。
- 切换节点、隐藏页面或打开其他节点不取消任务。
- 源图层处理中被移动时仍按冻结位置插入；源图层被删除时，结果先保存为项目资源并标记“待插入”，提示用户选择插入位置。
- 模型不支持图生图、多参考图、尺寸或目标数量时，提交按钮保持可见但禁用，并显示具体原因。
- 某个参考资源失效时，操作栏标出对应 `@选区N` 或 `@参考图N`，阻止提交，不静默忽略。
- 后台服务重启导致任务表丢失时，将任务标记失败并保留可重试参数。

## 14. 存储与资源生命周期

项目新增有界字段：

- 工具偏好：API、模型、尺寸、质量、数量、局部重绘参考模式和上次选区工具。
- 参考记录：资源 ID、固定名称、来源、顺序和尺寸。
- 父任务和子任务记录。
- 待插入结果。
- 生成图层的来源元数据。

所有二进制参考、蒙版和结果继续使用 OpenShop 内容寻址资源存储。移除某个参考时，只清理没有被任务、结果图层或其他项目引用的资源。删除节点时，取消该项目未完成任务并清理该项目无引用资源，不影响其他节点共享的内容寻址资源。

克隆节点保留已创建图层和稳定资源引用，但清空运行中任务、子任务、待插入结果和临时参考会话。

## 15. API 能力目录

HstarA 能力目录新增：

- `generative-fill`
- `local-redraw`

每个模型公开：

- 是否支持图生图。
- 是否支持蒙版。
- 是否支持多参考图。
- 参考图数量上限。
- 单次输出数量上限。
- 支持尺寸和质量档位。
- 是否支持批量输出。

OpenShop 只读取公开能力和保存 ID，不保存密钥。配置或模型被删除时显示“配置不可用”，不静默切换。

## 16. 测试与验收

### 16.1 入口和选区

- 两个按钮无选区时仍可点击。
- 点击后自动进入上次选区工具并等待用户框选，首次默认矩形选框。
- 矩形选框、套索、像素选区、多区域和取消选区状态正确。
- 有选区时直接展开底栏，无选区时不上传资源或创建任务。

### 16.2 底部操作栏

- 等待选区提示和参数输入状态原位切换。
- 只有局部重绘显示参考模式、缩略图、`＋` 和 @ 快捷窗口。
- 缩略图随选区、参考模式和可见图层实时刷新。
- 操作栏不存在任何种子控件，任务和项目 JSON 不含 `seed`。

### 16.3 参考与 @

- `＋` 覆盖当前选区、项目图层、本地上传和素材库。
- 引用名称稳定生成 `@选区N / @参考图N`。
- 所有添加参考都随请求发送，@ 只传递语义映射。
- 参考资源缺失时显示精确名称并阻止任务。

### 16.4 多结果图层

- 测试数量 `1` 到模型上限，不局限于三张。
- 目标 N 张时按成功数自动创建同数目的默认可见图层。
- 图层位置、透明边界、插入顺序和命名正确。
- 部分成功和补生成剩余数量正确。

### 16.5 隐藏运行

- 任务运行中关闭 OpenShop，只隐藏界面，iframe、轮询、上传、建层和自动保存持续运行。
- 隐藏完成后立即生成图层并更新节点卡片。
- 同时操作普通节点和另一个 OpenShop 节点，旧任务不受影响。
- 再次打开原节点复用实时会话，不重新加载。
- 主动取消和删除节点才终止任务。

### 16.6 隔离、视觉和回归

- 普通/智能画布、同画布多节点和克隆节点互相隔离。
- 迟到响应、服务重启、源图层删除、节点删除和资源失效可控。
- 视口覆盖 `1440 x 1000`、`1920 x 1080`、`430 x 932` 和 `4096 x 4096`。
- 底栏、缩略图和 @ 窗口不遮挡、重叠或溢出。
- 多隐藏会话设内存预算，任务完成且保存成功前不得回收。
- OpenShop 单元、Playwright、普通/智能画布集成、构建镜像、编码健康和 HstarA 根测试全部通过。

## 17. 实施顺序

1. 定义能力目录、父子任务、参考资源和输出规范化契约。
2. 扩展项目元数据、资源引用和克隆/删除清理语义。
3. 实现项目级后台父子任务和部分成功。
4. 实现 OpenShop 选区入口、两阶段底栏和参数偏好。
5. 实现局部重绘参考模式、缩略图、`＋` 和 @ 快捷引用。
6. 实现透明局部结果和多图层自动插入。
7. 重构宿主为多会话隐藏运行，增加节点卡片进度同步。
8. 完成普通/智能画布、多节点、隐藏运行、移动端和 4K 门禁。

## 18. 完成标准

只有同时满足以下条件，阶段 5A 才算完成：

1. 两个独立按钮在无选区时可进入 OpenShop 原生选区流程。
2. 底部原位操作栏代替独立页面和右侧面板。
3. 局部重绘支持两种主参考模式、实时缩略图、额外参考和 @ 映射。
4. 生成 N 张时按成功数自动创建同数目的默认可见独立图层。
5. 隐藏 OpenShop 页面不打断任何任务、轮询、上传、建层或保存过程。
6. 项目、节点、画布和隐藏会话之间严格隔离。
7. 项目和任务数据不包含密钥、内联图片或种子字段。
8. 全部自动化、视觉、移动端、4K、编码和全仓回归门禁通过。
