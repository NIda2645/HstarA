# 智能画布修改文字生图模型选择设计

## 目标

在智能画布的“修改文字”窗口中增加独立的生图配置入口。用户无需移动画布或重新打开生图节点底部控制栏，即可在完成文字修改后选择生成引擎、平台、模型、尺寸、分辨率、质量、数量及引擎特有参数，并使用已确认的配置执行图片生成。

本功能只扩展“修改文字”模式。“消除文字”现有配置和执行逻辑保持不变。

## 用户界面

### 主窗口

- 在底部“取消”按钮左侧增加“选择生图模型”按钮。
- 按钮左边缘与顶部“修改文字”页签左边缘对齐。
- 底部区域改为两行：
  - 第一行显示“选择生图模型”“取消”“应用修改”。
  - 第二行显示已确认配置的只读摘要。
- 尚未确认配置时，摘要显示“未选择生图模型”，“应用修改”保持禁用。
- 已确认配置时，摘要优先显示：生成引擎、API 平台或工作流、模型、尺寸与分辨率、质量、数量。
- 引擎没有质量或数量参数时，不显示虚假占位项。

### 二级配置窗口

- 点击“选择生图模型”后，在修改文字窗口内部打开二级配置层。
- 二级层覆盖主窗口内容，但不关闭主窗口、不清空识别文字、不移动画布。
- 顶部使用向左箭头作为返回入口，避免与主窗口右上角关闭按钮形成两个相同的关闭图标；底部提供“取消”和“确认”。
- “取消”丢弃本次草稿，不改变已确认配置。
- “确认”完成参数校验后保存草稿，关闭二级层并刷新主窗口摘要。
- 二级层使用稳定的固定区域和内部滚动，不改变文字修改主窗口的外部定位。

### 二级配置窗口排版

- 保持当前“生成引擎”下拉按钮的宽度、高度和字号，不压缩该控件。
- 生成引擎下方采用单列列表，不再把多个配置按钮紧密挤在同一行。
- 基础配置按以下顺序分别占据一整行：`API 平台`、`生图模型`、`尺寸`、`分辨率`、`质量`、`生图数量`。
- “尺寸”只负责画面比例或自定义宽高，常规预设显示为 `9:21`、`16:9`、`3:4` 等比例值。
- “分辨率”与“尺寸”完全拆分，当前值单独显示，点击后提供 `1K`、`2K`、`4K` 三档。
- `1K`、`2K`、`4K` 始终显示；当前模型不支持的档位置灰并标注“该模型不支持”，不得提交无效分辨率参数。
- 切换平台或模型后立即重新计算尺寸与分辨率能力；若原草稿值失效，选择该模型支持的默认值并在界面中同步显示。
- 每个列表按钮使用统一高度、圆角和左右内边距；字段标签左对齐，当前值右对齐，列表行之间使用一致的垂直间距。
- 长平台名、模型名或工作流名在单行内省略，并通过现有标题提示显示完整值；关键错误信息不得省略。
- 引擎特有的附加参数继续显示在基础配置之后，并沿用相同的单列、等高和等间距规则。
- 内容列表独立滚动，底部“取消”和“确认”固定在可视区域，不被较长的模型列表或动态参数遮挡。

### 画布缩放与定位

- 修改文字窗口和选择生图模型二级层继续挂载在画布世界坐标中，跟随来源节点移动，并与图片节点使用同一 `viewport.scale`。
- 窗口、文字、按钮和间距随画布缩小同步缩小、随画布放大同步放大，不使用反向缩放抵消画布倍率。
- 边界约束直接使用窗口在画布世界坐标中的宽高，保证定位计算与节点和窗口的实际缩放结果一致。
- 画布缩放、拖动节点或调整窗口大小后，窗口仍贴近来源节点，并保持在可视画布边界内。

## 引擎范围

配置窗口覆盖智能画布现有的全部图片生成引擎：

- API 图片生成，包括当前 API 列表中的 RunningHub、Seedream 等平台和模型；
- 火山引擎图片生成；
- ModelScope 图片生成；
- ComfyUI 图片工作流；
- RunningHub 模型、AI 应用和工作流。

文字修改的输入和输出均为图片，因此不展示视频生成配置。RunningHub 和 ComfyUI 仅展示能够进入现有图片生成链路的配置；不兼容的配置在确认时给出明确提示。

每种引擎展示与智能画布生图节点底部控制栏一致的有效参数。引擎不支持某项参数时不强行补齐该参数。

尺寸和分辨率沿用现有生成配置的数据字段与模型能力信息，界面拆分不引入第二套配置协议。没有独立分辨率能力的引擎可以隐藏该行；存在分辨率能力但只支持部分档位的引擎必须显示全部 `1K / 2K / 4K` 选项，并将不支持的档位置灰。

## 状态模型

文字修改状态增加两个相互隔离的配置状态：

- `generationSettingsDraft`：二级窗口当前编辑的草稿。
- `generationSettings`：用户点击“确认”后生效的完整配置。

同时增加 `generationSettingsConfirmed` 标志，用于区分“从节点预填但尚未确认”和“用户已确认”。

首次打开二级窗口时：

1. 如果当前图片已有已确认配置，以该配置初始化草稿。
2. 否则从当前图片节点的 `runSettings`、节点最近配置和画布默认配置中按现有优先级生成草稿。
3. 仅预填草稿，不自动将其标记为已确认，主窗口仍显示“未选择生图模型”。

配置按 `node.smartTextEditStates[imageIndex]` 保存，与当前识别文字状态使用同一图片索引边界。保存内容只包含可序列化的普通配置数据，不保存 DOM、函数、请求对象或 API 密钥。

## 组件边界

### 配置会话控制器

负责：

- 从节点和画布设置创建隔离草稿；
- 打开、取消和确认二级窗口；
- 校验与规范化各引擎参数；
- 生成主窗口摘要；
- 将确认后的配置传给生成链路。

控制器不得在用户确认前修改全局 `settings`、节点 `runSettings`、当前生图面板或最近使用配置。

### 共享生成配置渲染

现有生图配置渲染逻辑保持权威。新增一个有明确输入输出的隔离适配层：

- 输入为配置草稿、目标容器和重新渲染回调；
- 输出为更新后的草稿；
- 平台或模型变化时沿用现有模型过滤、默认分辨率、动态字段和参数规范化规则；
- 不通过复制一套静态平台或模型清单实现；
- 不把二级窗口绑定到主生图面板的全局 DOM。

如现有渲染函数依赖全局状态，提取最小的纯配置辅助函数和容器级事件绑定，不重写整套智能画布设置系统。

### 生成执行

“应用修改”执行以下流程：

1. 校验存在已确认的 `generationSettings`。
2. 根据修改后的文字生成现有文字替换提示词。
3. 关闭文字修改窗口。
4. 将确认配置作为 `overrideSettings` 传入 `runSmartImageTextGeneration`。
5. 沿用现有原图参考、待生成输出节点、任务状态、日志、失败回滚和保存逻辑。

一次点击只发起一次生成请求，不增加自动重试。

## 配置摘要

摘要由规范化后的确认配置生成，而不是读取二级窗口当前 DOM。建议格式如下：

`API生成 / RunningHub / seedream-v... / 9:21 · 4K / 自动 / 1张`

对于其他引擎：

- ModelScope 显示模型或自定义模型、尺寸和数量；
- ComfyUI 显示实例、工作流及关键输出尺寸；
- RunningHub 显示模型、应用或工作流名称，以及实际存在的关键参数。

摘要允许换行或省略非关键引擎特有字段，但平台、模型或工作流不能被省略到无法辨认。

## 错误处理

- 未确认配置时禁止执行“应用修改”。
- 平台没有可用图片模型时，在二级窗口显示错误并保留草稿。
- 自定义尺寸缺少宽或高时禁止确认。
- 当前分辨率不在所选模型支持范围内时禁止确认，并将用户引导到“分辨率”按钮重新选择。
- ComfyUI 未选择实例或工作流时禁止确认。
- RunningHub 缺少必填动态字段时禁止确认，并指出缺失字段。
- 配置在重新打开后因 API 设置变化而失效时，保留可识别字段，要求用户重新确认。
- 确认和取消只改变文字修改会话，不创建输出节点，不发送网络请求。

## 兼容性与持久化

- 旧画布不存在新字段时按未选择状态处理，不迁移或修改旧节点数据。
- 现有文字识别 API、识别结果、语音输入和“消除文字”流程保持兼容。
- 现有生图节点底部配置仍独立工作；文字修改确认不会反向覆盖节点的全局配置。
- 确认后的配置随画布保存和重新载入恢复。

## 测试与验收

### 自动化测试

- 主窗口包含新按钮、两行底部布局和默认未选择摘要。
- 未确认配置时“应用修改”禁用。
- 首次打开草稿继承节点配置，但不自动确认。
- 取消二级窗口不修改已确认配置。
- 确认后摘要和持久化状态同步更新。
- API、火山引擎、ModelScope、ComfyUI、RunningHub 分别覆盖至少一个配置路径。
- 平台切换会刷新模型和引擎特有字段。
- 二级配置层采用六行基础单列布局，按钮等高、间距一致，尺寸与分辨率使用独立控件。
- 分辨率控件显示 `1K / 2K / 4K`，并按模型能力正确禁用不支持的档位。
- 不同 `viewport.scale` 下窗口与图片节点保持相同缩放倍率，定位边界按未反向缩放的画布世界坐标占用范围计算。
- 较长配置内容滚动时底部“取消”和“确认”始终可见。
- `applySmartTextModification` 将确认配置传入 `runSmartImageTextGeneration`。
- 旧节点无新字段时能够正常打开和识别文字。
- 编码审计、静态缓存完整性和智能画布相关测试通过。

### 浏览器验收

- 在端口 `3000` 的真实智能画布中打开包含识别文字结果的修改窗口。
- 检查按钮对齐、六行单列配置、尺寸与分辨率拆分、二级窗口边界、内部滚动、亮色和暗色主题。
- 在缩放画布、移动来源节点和调整浏览器窗口后，确认二级窗口尺寸稳定并持续贴近来源节点。
- 切换至少两个分辨率能力不同的模型，确认 `1K / 2K / 4K` 的可用和置灰状态随模型正确刷新。
- 分别选择 API 和至少一个非 API 引擎，确认摘要正确。
- 取消一次草稿修改，确认原配置未改变。
- 刷新画布并重新打开同一图片，确认已确认配置恢复。
- 未经用户明确授权，不执行可能产生费用的真实生图请求；可通过受控测试替身验证请求配置。
