# OpenShop 文字与颜色快捷交互设计

## 目标

将右侧“文字”属性面板中的字体搜索输入框改为只读下拉框。用户只通过展开列表、滚动和单击选择字体，不再输入或搜索字体名称。

## 交互

- 控件默认显示当前文本对象、字符选区或输入光标正在使用的字体。
- 点击控件展开实时字体目录中的全部字体，不限制固定数量。
- 展开后自动滚动到当前字体，并以选中状态标识该项。
- 列表支持鼠标滚轮和触控板滚动；单击字体立即应用并关闭列表。
- 点击控件和列表以外的区域，或按 `Esc`，立即关闭列表。
- 再次点击已展开的控件会关闭列表。
- 控件不接受键盘文字输入，不提供搜索或自动补全。
- 字体列表继续使用对应字体预览名称，并保留缺失字体状态提示。

## 实现边界

- 保留现有本机字体实时加载、刷新、项目字体引用、字符选区和输入光标作用范围。
- 使用现有自定义列表，不改为原生 `select`，以保留字体预览和缺失状态样式。
- 字体目录只在展开时渲染；打开后定位当前项，避免初始滚动位置不明确。
- 事件监听继续由文字属性控制器管理，控制器销毁时一并移除。

## 数字键盘确认输入

- 文本对象处于编辑状态时，按数字键盘的 `NumpadEnter` 确认当前文字、退出编辑状态并保留修改。
- 主键盘的普通 `Enter` 继续插入换行，不触发确认。
- 非文本编辑状态以及表单输入框、下拉框获得焦点时，不拦截 `NumpadEnter`。
- 确认操作沿用现有文字编辑退出、历史记录和项目脏状态流程，不重复创建历史记录。

## 前景色和背景色填充快捷键

- `Alt + Delete` 使用当前前景色填充，`Ctrl + Delete` 使用当前背景色填充。
- 单独按 `Delete` 继续执行现有的对象、图层或选区删除逻辑；`Backspace` 不参与颜色填充组合键。
- 存在像素选区时，只填充当前活动图像图层与选区相交的像素。
- 没有像素选区时，填充当前活动图像图层的全部像素。
- 当前活动图层没有可编辑图像时，不修改其他图层，并显示明确提示。
- 文字对象正在编辑以及输入框、文本域、下拉框或可编辑元素获得焦点时，不触发颜色填充。
- 每次成功填充只产生一条历史记录并触发一次项目脏状态，保持撤销、重做和项目保存一致。

## 验证

- 单元测试验证控件只读、点击切换、完整字体列表、当前项标识、选择应用、外部点击和 `Esc` 关闭。
- E2E 验证长字体列表可以滚动，打开时定位当前字体，选择后项目状态同步。
- 键盘测试验证 `NumpadEnter` 确认退出、普通 `Enter` 换行，以及非文字编辑状态不被误触发。
- 快捷键测试验证 `Alt+Delete` 前景色、`Ctrl+Delete` 背景色、普通 `Delete` 原行为和可编辑焦点隔离。
- 像素测试验证矩形选区、像素遮罩选区和无选区三种填充范围，并确认非活动图层不发生变化。
- 桌面和移动视口检查下拉列表不超出右侧面板边界。
