# 智能画布消除文字提示词强化设计

## 目标

强化智能画布“消除文字”的专用生图提示词，使模型只移除图片中的可见文字信息，并最大程度保持人物、表情、图形、贴图、线条、颜色、光影、纹理、构图与其他设计元素不变。

## 已确认范围

- 仅调整 `smartTextErasePrompt()`，不引入 OCR、遮罩或新的后端接口。
- 保留用户在消除文字窗口选择的 API 平台、生图模型、尺寸、分辨率、质量和数量。
- 不锁定原图比例或像素尺寸；目标画布不同时允许必要的缩放、裁切或扩展，但禁止主动重绘非文字内容。
- 提示词覆盖文字、字母、数字、标点、字幕、标签、海报文案和文字型 Logo，并禁止生成任何新文字。
- “修改文字”和普通生图提示词保持不变。

## 质量边界

提示词强化能够提高非文字内容一致性，但无法像遮罩合成一样保证遮罩外逐像素相同。最终一致性仍受用户所选模型及目标尺寸影响。

## 验证

- 回归测试必须断言专用提示词包含完整的删除范围、非文字保护范围和目标尺寸适配限制。
- 回归测试必须确认消除流程继续使用用户选择的运行设置，且未增加原图尺寸锁定。
- 运行智能文字专项测试、编码审计、缓存完整性检查和源码门禁。
