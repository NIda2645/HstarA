# 回收站删除全部设计

## 目标

在项目工作台回收站标题栏的关闭按钮左侧增加“删除全部”按钮。用户确认后，一次性彻底删除回收站中的全部画布，并同步清理每个画布关联的 OpenShop 项目、AI 任务和旁路资源。

## 交互

- “删除全部”与关闭按钮位于同一标题栏操作区，并排显示。
- 回收站为空时按钮禁用。
- 点击按钮打开站内确认层，文案为“是否确认删除回收站内全部可回收画布？”和“删除后无法恢复。”。
- 点击取消关闭确认层，不改变数据。
- 点击确认后锁定相关按钮并显示执行状态，避免重复请求。
- 成功后关闭确认层，重新加载画布、回收站列表和数量；失败时保留数据并显示中文错误提示。

## 后端

新增 `DELETE /api/canvases/trash/purge-all`。接口仅处理 `deleted_at` 为真的画布，不删除活动画布。单项彻底删除和批量彻底删除共用一个底层清理函数，该函数在现有画布锁和 OpenShop 生命周期锁内删除关联项目、取消任务、删除画布文件，并在需要时执行资源回收。

响应格式为 `{ "ok": true, "purged": N }`。空回收站返回 `purged: 0`。

## 验证

- 静态前端测试覆盖按钮位置、空状态禁用、确认层和批量请求。
- API 测试使用临时数据目录，覆盖仅删除回收站画布、保留活动画布、清理 OpenShop 关联数据及空回收站。
- 运行缓存引用检查、JavaScript 语法检查、文本编码审计和 `git diff --check`。
- 浏览器验证只使用隔离测试画布，不删除用户已有回收站内容。
