# OpenShop OCR 几何与艺术字体局部重绘设计

## 目标

修复图像识别结果创建为横排或直排文本图层后，文字可见大小和位置与原图不一致的问题；同时用基于原图区域和蒙版的局部重绘流程，替换现有透明字形生成流程。

## 已确认行为

- 横排和直排文字使用同一套“可见字形边界对齐 OCR 四点框”的原则。
- 文本图层保持可编辑，最终 `scaleX` 和 `scaleY` 为 `1`。
- 艺术字体生成内容取文本图层当前编辑后的文字，原始识别文字只作为视觉风格来源。
- 艺术字体结果是原图局部重绘图块，不再是透明字形 PNG。
- 重绘图块中蒙版外的像素由后端强制恢复为原图像素，保证文字以外区域不变化。
- 旧的“抠除背景、只发送孤立字形、拒绝矩形背景图块”流程被完整替换。

## 根因

### OCR 文本图层

当前 `fitTextUniformly` 使用 Fabric 文本对象的 `width` 和 `height` 计算统一缩放，再把文本对象左上角放到 OCR 四点框第一个点。Fabric 文本尺寸包含字体行框的上、下空白，而 OCR 四点框描述的是原图中的可见字形。把行框塞入字形框会缩小真实字形；用行框左上角对齐字形左上角会产生位置偏移。该问题同时影响横排和直排，直排因自定义布局的字格和行距更明显。

### 艺术字体

当前后端调用 `prepare_art_font_reference` 抠除裁剪区域背景，只把孤立透明字形发送给图像模型。提示词禁止重建背景，`normalize_art_font_output` 又会抠除背景并拒绝场景式矩形图块。该流程与局部重绘目标相反，也会丢弃上游已经生成成功的完整局部图块。

## OCR 几何设计

新增独立的 OCR 字形布局模块，负责：

1. 将归一化四点坐标转换为画布像素坐标和局部旋转矩形。
2. 创建匹配本机字体后的可编辑文本对象，初始不使用对象缩放。
3. 在离屏 Canvas 中以对象本地坐标渲染文字，并读取 alpha 像素的真实可见边界。
4. 横排文字以 OCR 框可见高度求解字号，再以主轴宽度求解字距。
5. 直排文字以 OCR 框可见宽度求解字号，再以主轴高度求解字距。
6. 多行横排或多列直排继续使用识别结果中的行距，并以可见边界做最终小幅迭代校正。
7. 根据可见边界相对文本对象中心的偏移，经过旋转矩阵补偿 `left` 和 `top`。
8. 无法把主轴长度精确匹配时保持字形比例，并沿主轴居中，不允许非等比压缩字形。
9. 最终对象写入真实求解后的 `fontSize`、`charSpacing` 和 `lineHeight`，保持 `scaleX=1`、`scaleY=1`。

离屏测量失败时不恢复旧的行框缩放；使用基于 Canvas `measureText` 的保守度量，并在 OCR 框内按可见横竖主轴对齐。

## 艺术字体局部重绘设计

### 输入准备

后端从最初用于 OCR 的完整像素图层素材中，根据 `hstarOcrQuad` 计算轴对齐裁剪框。裁剪框在文字四点框外围增加受限留白，为模型提供原始背景、材质和邻近结构上下文。

后端同时生成与裁剪图块同尺寸的编辑蒙版：

- 蒙版覆盖原文字四点区域并增加少量安全扩展，用于清除原字边缘、描边和阴影。
- 蒙版不能扩展到裁剪图块之外。
- 裁剪框和蒙版几何以原始源图像素为准，并随结果返回给前端。

### 模型请求

图像模型收到两个输入：

- 原图局部区域，角色为 `source`。
- 编辑蒙版，角色为 `mask`。

提示词要求：

- 只在蒙版内把原文字替换为当前编辑文字。
- 只渲染当前编辑文字，绝不恢复原字符。
- 匹配原文字的可见大小、位置、色彩、字重、艺术风格、描边、阴影、材质、角度、字距和横竖方向。
- 输出尺寸与输入局部区域完全一致。
- 不添加额外字符、标志、装饰或色彩晕染。
- 蒙版外区域保持不变。

支持原生蒙版编辑的提供商使用图片编辑接口；仅支持多参考生图的提供商仍同时接收源图和蒙版，并由后端执行最终像素保护。

### 输出保护

新增局部重绘归一化函数：

1. 解码并校验生成图像的安全尺寸。
2. 将生成图像缩放或裁剪到源局部图块的精确尺寸；不改变裁剪框在画布上的尺寸。
3. 使用蒙版把生成图像和原图局部区域合成。
4. 蒙版外像素逐像素复制原图；蒙版边缘只允许受控羽化。
5. 输出保持不透明局部图块，不执行透明抠字、背景去除、色彩晕染清理或场景矩形拒绝。
6. 返回图块宽高和原图像素坐标 `placementBox`，不再返回用于透明字形缩放的 `contentBox`。

### OpenShop 落位

OpenShop 将局部图块创建为新的像素图层：

- `left` 和 `top` 直接取 `placementBox`。
- `scaleX=1`、`scaleY=1`、`angle=0`，因为旋转文字已经在局部图块像素中完成。
- 图层位于原始像素图层和可编辑文本载体上方。
- 成功落位后隐藏可编辑文本载体，但不删除它。
- 再次编辑载体文字并生成时创建新一代结果，任务身份、恢复和幂等逻辑保持不变。

## 数据协议

艺术字体任务快照继续保存：

- `originalText`
- `currentText`
- `quad`
- `document`
- `visualProfile`
- `requestGeneration`

任务结果改为：

```json
{
  "assetId": "...",
  "url": "...",
  "name": "...",
  "mime": "image/png",
  "width": 640,
  "height": 240,
  "placementBox": {"x": 320, "y": 180, "width": 640, "height": 240}
}
```

`placementBox.width`、`placementBox.height` 必须与 PNG 尺寸一致，并且整个矩形位于快照文档范围内。

## 错误处理

- OCR 可见字形无法测量时使用保守度量，不创建零尺寸或非有限变换。
- 源图、四点框、裁剪框或蒙版无效时，艺术字体任务失败且不调用上游。
- 模型结果无法解码或尺寸不安全时，不创建图层，保留可重试任务记录。
- 模型成功但前端落位失败时，恢复文本载体可见性并移除半创建图层。
- 不自动重试瞬时断线；等待用户再次主动执行。

## 验证

自动化测试覆盖：

- 横排与直排可见字形边界对齐目标四点框。
- 识别源图缩放到模型尺寸后再映射回画布的坐标准确性。
- 最终文本对象 `scaleX=1`、`scaleY=1`。
- 当前编辑文字进入艺术字体提示，原始文字不进入文字内容提示。
- 请求同时包含局部源图和蒙版。
- 蒙版外输出像素与原图逐像素一致。
- 结果使用 `placementBox` 原尺寸落位，不再使用 `contentBox` 缩放。
- 横排、直排、旋转文字和带描边阴影文字。
- 上游成功、输出无效、任务恢复、重复恢复和失败回滚。

真实验证使用当前配置的图像模型执行至少一组“原字改为新字”的局部重绘，并检查生成日志、结果图层、背景不变区域和画布落位。
