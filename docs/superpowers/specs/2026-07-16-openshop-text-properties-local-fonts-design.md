# OpenShop 文字属性与本机字体设计

## 目标

OpenShop 的文字编辑交互对齐 Photoshop 2023：创建、选中或进入文字编辑时，右侧自动打开文字属性面板；用户可以搜索并使用 Windows 本机已安装字体，并在对象、文字选区和输入光标三个层级正确应用样式。

本功能不创建新页面，不复制或嵌入本机字体文件，也不改变“文字提取”和“去除文字”两个独立 AI 功能。

## 当前问题

- 顶部文字栏只修改新建文字的默认状态，不能稳定修改当前文字对象或选区。
- 右侧“属性”页是通用调整与图层样式，没有独立的文字属性页，也不会随文字选择自动切换。
- `openshop-font-catalog.js` 只探测固定常用字体和项目缺失字体，无法列出本机完整字体目录。
- Fabric `IText` 已保存 `fontFamily`、`fontSize`、`fontWeight`、`fontStyle` 等属性，但缺少统一的选择范围、控件同步、历史记录和项目脏状态管理。

## 架构

### HstarA 字体目录接口

新增只读接口：

```text
GET /api/openshop/fonts
GET /api/openshop/fonts?refresh=1
```

响应结构：

```json
{
  "platform": "windows",
  "cached": true,
  "fonts": [
    {
      "family": "Arial",
      "label": "Arial",
      "styles": [
        {
          "id": "arial-400-normal",
          "label": "Regular",
          "weight": 400,
          "italic": false,
          "localNames": ["Arial"]
        }
      ]
    }
  ]
}
```

Windows 使用标准库 `ctypes` 调用 Win32 字体枚举能力，并结合注册表字体信息规范化字体家族、字形、粗细和斜体。过滤 `@` 开头的竖排别名，按 `family + weight + italic` 去重。响应不得包含字体文件路径、字体二进制内容或用户目录。

目录在服务进程内缓存。`refresh=1` 重新枚举，用于用户安装字体后刷新。非 Windows 平台返回现有常用字体回退目录，不阻塞编辑器启动。

### OpenShop 字体目录

扩展 `openshop-font-catalog.js`：

- 启动时异步读取 `/api/openshop/fonts`。
- 合并后端目录、现有常用字体和项目 `fontRefs`。
- 保留缺失字体原名称，不自动替换。
- 提供搜索、家族字形查询、刷新和可用性状态。
- 通过 CSS `font-family` 使用系统字体，不下载字体文件。

字体接口失败时继续使用常用字体回退，并在文字面板显示可重试错误，不影响项目打开。

### 文字属性控制器

新增独立模块 `host/openshop-text-properties.js`，负责：

- 注入右侧“文字”标签和面板内容。
- 监听 Fabric 文字对象选择、编辑进入、文字选区变化、文字变化和编辑退出。
- 统一同步顶部文字快捷栏与右侧文字面板。
- 按作用范围应用样式并生成历史记录。
- 更新 `fontRefs`、图层面板、画布渲染和 `openshop:project-dirty`。

文字属性不并入 AI 文字工具控制器，避免字体编辑与模型任务生命周期耦合。

## 右侧文字面板

在第一组右侧标签中加入“文字”，与“图层 / 属性 / 对齐”并列。面板保持 OpenShop 现有紧凑深色工作台样式，不使用新窗口或大卡片。

控件包括：

- 可搜索字体家族选择器，显示当前状态和字体名称预览。
- 字形/粗细选择器。
- 字号，界面单位为“点”，内部按 96 DPI 与 Fabric 像素值换算。
- 行距：自动或自定义。
- 字距/跟踪。
- 字偶距：自动、度量和数值入口。
- 文字颜色。
- 左对齐、居中、右对齐和两端对齐。
- 粗体、斜体、下划线和删除线。
- 刷新本机字体按钮。

字体列表使用可搜索弹层，不把数百个字体直接铺成超长原生下拉框。面板必须适配当前右栏宽度，在 1440、1920、4K 和窄屏视口中不遮挡画布或底部状态栏。

## 自动切换

以下事件自动切换到右侧“文字”标签：

- 使用文字工具新建 `IText`。
- 单击选择 `IText` 或 `Textbox`。
- 双击或键盘操作进入文字编辑。
- 文字选区发生变化。

取消选择后不强制跳回“图层”，避免面板来回闪动；用户可手动切换任意右侧标签。

## 属性作用范围

### 文字对象

文字对象被选中但未进入编辑时，字体、字号、字形、颜色和装饰应用到整个对象。

### 文字选区

进入编辑且 `selectionStart < selectionEnd` 时，Fabric 支持的字符样式通过 `setSelectionStyles` 只应用到选中字符：

- `fontFamily`
- `fontSize`
- `fontWeight`
- `fontStyle`
- `fill`
- `underline`
- `linethrough`

混合样式显示“混合”。修改一个属性时只覆盖该属性，不抹掉其他字符级样式。

### 输入光标

进入编辑且没有文字选区时，控制器保存当前插入样式。后续输入字符立即应用该样式；已有字符不被修改。退出编辑后清除临时插入状态。

### 段落和对象级属性

Fabric 5 的 `textAlign`、`lineHeight` 和 `charSpacing` 是文字对象级属性，因此段落对齐、行距和字距作用于当前文字对象。界面明确按段落属性展示，不伪装成字符级能力。字偶距“自动 / 度量”控制浏览器字体度量模式；手动数值使用对象级字距实现。

## 顶部快捷栏同步

现有 `#opt-text` 保留，作为 Photoshop 风格的快速控制入口：

- 切换文字工具但未选择对象时，修改新建文字默认值。
- 存在活动文字对象时，与右侧面板显示同一状态，并按相同范围应用。
- 右侧属性变化会同步顶部字体、字号和颜色。
- 顶部变化会同步右侧面板。

## 字体缺失和项目持久化

- 项目继续通过文字对象属性和 `fontRefs` 保存字体引用。
- 不保存字体文件路径，不把本机字体复制到项目资源。
- 重新打开项目时扫描字体目录；缺失字体保留原名称并显示“缺失字体”。
- 用户可通过现有字体管理功能主动替换，替换行为进入撤销历史。
- 字体应用失败时恢复原样式并提示错误，不产生空白文字或静默回退。

## 历史记录和保存

- 连续输入沿用现有文字编辑历史行为。
- 数字输入和颜色变化在提交时生成一次历史记录；拖动或键入过程不重复堆叠历史。
- 字体、字形和开关命令每次用户确认生成一次历史记录。
- 每次成功属性修改都渲染画布、更新图层面板、扫描 `fontRefs` 并发送 `openshop:project-dirty`。

## 测试

### 后端

- Windows 字体家族和字形枚举。
- `@` 竖排别名过滤与重复项合并。
- 缓存命中和 `refresh=1` 刷新。
- 响应中不含字体路径或字体二进制内容。
- 非 Windows 回退目录。

### 前端单元测试

- 自动加载、搜索、刷新和错误回退。
- 新建、选中和进入编辑时自动切换文字标签。
- 整个对象、字符选区和输入光标三种样式作用范围。
- 混合样式读取和单属性覆盖。
- 顶部快捷栏与右侧面板双向同步。
- 历史记录、项目脏状态和 `fontRefs` 更新。

### E2E

- 在隔离的 HstarA 工程服务中读取真实 Windows 字体。
- 新建文字后自动显示文字属性面板。
- 使用 `Microsoft YaHei UI` 或其他已安装字体修改中英文混排文字。
- 修改完整常用属性，保存项目并重新打开，视觉和属性保持一致。
- 桌面、窄屏和 4K 下无控件遮挡或溢出。

E2E 只创建登记后的测试画布，并沿用精确 ID 永久清理机制；不访问稳定安装版画布数据，也不调用生图 API。
