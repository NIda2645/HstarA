# OpenShop 编辑器交互可靠性修复设计

## 背景

本轮修复覆盖 OpenShop 编辑器中六项直接影响高频操作的问题：字体下拉框无法可靠关闭、字体顺序不符合中文用户习惯、文字工具重复创建文本、画板四边吸附体验不完整、橡皮擦反馈延迟，以及前景色/背景色系统颜色弹窗中的吸管不可用。

修复保持现有 HstarA 图文分层项目结构、OpenShop 文档格式、图层顺序、导出尺寸和后台生成任务协议不变。

## 目标

1. 字体下拉框点击外部后立即关闭，重新打开时仍能定位当前字体。
2. 字体列表默认将中文字体排在其他字体之前。
3. 文字工具点击已有文本时进入编辑，点击文本外部时才创建新文本。
4. 普通图层能够分别吸附画板左、右、上、下四条边线，并保留中心线、整图重合和局部重绘选区吸附。
5. 橡皮擦在拖动过程中提供连续反馈，抬笔时只提交一次最终路径和历史记录。
6. 前景色和背景色改用 OpenShop 自有颜色面板，面板吸管只采样当前 OpenShop 画布。

## 非目标

- 不支持跨应用或全屏幕系统级取色。
- 不重构全部 Fabric 工具状态机。
- 不改变字体安装、字体文件读取或缺失字体替换协议。
- 不增加吸附开关；几何吸附继续默认常开。
- 不改变橡皮擦对图层顺序和混合模式的既有语义。

## 字体下拉框

### 关闭规则

字体列表继续使用当前自定义按钮和滚动列表，不恢复搜索输入。列表打开后：

- 点击字体选项会应用字体并关闭列表。
- 点击列表和触发按钮以外的任意 OpenShop 区域会关闭列表。
- 按 `Esc` 会关闭列表并保留当前字体。
- 面板切换、文字目标变化或控件销毁时不能遗留可见列表。

当前 `hidden` 属性被 `.hstar-font-list` 的作者样式覆盖。修复必须为隐藏状态增加明确的 CSS 规则，事件处理仍负责维护 `hidden` 和 `aria-expanded`，两者保持同步。

### 中文优先排序

字体按两级规则排序：

1. 字体语言标记为 `zh`，或字体 `family` / `label` 包含中日韩统一表意文字时，归入中文字体组。
2. 中文字体组排在其他字体组之前；组内使用中文本地化比较器按显示名称排序。

字体可用、缺失和已替换状态不参与优先级，避免状态变化导致列表大范围跳动。当前选中字体仍通过滚动定位显示。

## 文字工具状态

文字工具需要区分“命中已有文本”和“命中空白区域”两条路径。

### 命中已有文本

- 仅 `text`、`i-text` 和 `textbox` 类型可以成为文字工具目标。
- 单击目标时将其设为活动对象并进入编辑状态。
- 已经处于编辑状态时，不创建新对象，由 Fabric 继续完成光标定位和选区操作。
- 右侧面板继续自动切换到文字属性。

### 命中空白区域

- 若指针未命中文本对象，则按当前字体、字号、颜色、粗体和斜体设置创建一个新文本。
- 新文本创建后立即进入编辑并只写入一次“添加文字”历史记录。

文字工具交互配置只允许文本对象参与事件命中，不应让图片、形状或锁定图层对象在文字工具下变得可移动。

## 四边几何吸附

画板几何目标明确为：

- 对象左边与画板左边。
- 对象右边与画板右边。
- 对象上边与画板上边。
- 对象下边与画板下边。
- 对象水平中心与画板水平中心。
- 对象垂直中心与画板垂直中心。

X、Y 轴独立判定，同一轴选择容差内距离最小且优先级最高的目标。对象边线不跨吸附到画板相反边线，避免把图层吸到画板外部。

现有优先级保持不变：局部重绘选区、整图重合、画板边线/中心线、可选网格。Fabric 变换后边界用于判定，位置修正仍以对象原点为基准叠加同一偏移。新增测试必须分别覆盖左、右、上、下四边，而不是只用整图左上复位间接证明。

## 橡皮擦实时反馈

橡皮擦继续生成 `globalCompositeOperation = destination-out` 的 Fabric 路径，保证保存、撤销、重做和导出行为兼容现有项目。

绘制期间使用专用橡皮擦画笔提供逐帧反馈，并避免在每个指针移动事件中执行图层面板更新、历史序列化、导航器或直方图计算。抬笔后：

1. 将最终路径加入当前活动图层。
2. 设置透明擦除混合模式。
3. 只保存一次历史快照。
4. 只调度一次图层和派生面板刷新。

光标坐标等非关键状态按动画帧合并更新，不能阻塞 Fabric 的自由绘制事件。

## OpenShop 自有颜色面板

### 面板内容

点击右侧前景色或背景色色块时，不再触发隐藏的浏览器原生 `input[type=color]`。OpenShop 在色块附近打开自有弹窗，包含：

- 饱和度/明度二维色域。
- 色相滑条。
- 当前颜色预览。
- R、G、B 数值输入。
- “从画布取色”按钮。
- 确定和取消按钮。

前景色与背景色共用同一控制器，通过目标类型决定最终调用 `setFgColor` 或 `setBgColor`。

### 取色状态

点击“从画布取色”后：

1. 冻结面板当前草稿颜色并暂时收起弹窗。
2. 保存进入取色前的工具和目标色类型。
3. 将画布光标切换为十字准星。
4. 下一次有效画布单击调用现有 `HstarOpenShopCanvasSampler`。
5. 成功后更新对应前景色或背景色，并恢复原工具。

点击画板外部不改变颜色；`Esc` 取消取色并恢复原工具。取色过程不依赖浏览器 `EyeDropper` API，也不读取 OpenShop 之外的屏幕像素。

### 弹窗关闭规则

- “确定”提交草稿颜色。
- “取消”、`Esc` 或点击弹窗外部恢复打开前的颜色。
- 切换前景色/背景色目标时先关闭旧面板，再以新目标颜色初始化。
- 页面卸载或控制器销毁时移除全局事件监听。

## 组件边界

### `openshop-font-catalog.js`

负责中文字体分类和稳定排序，不处理下拉框 DOM。

### `openshop-text-properties.js` / `.css`

负责字体列表显隐、外部点击、键盘关闭和无障碍状态。

### OpenShop 主编辑器

负责文字工具命中路径、工具交互配置、吸附坐标应用和橡皮擦生命周期。

### `openshop-snap-engine.js`

负责纯几何计算，使用无 DOM 的单元测试覆盖全部边线。

### 新颜色面板控制器

独立管理颜色转换、弹窗草稿状态、取色状态和事件清理；通过注入的编辑器接口调用画布采样器和颜色设置方法。

## 错误处理

- 字体目录为空时显示空列表，不影响当前文本字体。
- 文本对象被锁定或已从画布移除时不进入编辑、不创建重复历史记录。
- 无效吸附矩形继续回退到普通网格或不吸附。
- 颜色采样越界或读取失败时保留原颜色并显示现有错误提示。
- 颜色输入超出 `0-255` 时限制到合法范围；非法文本不提交。

## 测试策略

### 单元测试

- 字体列表隐藏样式和外部关闭状态。
- 中文字体分组优先、组内稳定排序。
- 文字工具点击已有文本不增加对象，点击空白只增加一个对象。
- 左、右、上、下边线及中心线分别吸附。
- 橡皮擦绘制期间不写历史，完成后仅写一次。
- 颜色面板前景色/背景色提交、取消、越界采样、成功采样和工具恢复。

### 浏览器测试

- 展开字体列表后点击画布或右侧其他面板，列表不可见。
- 字体列表首组为中文字体并支持滚动选择。
- 文字工具重复点击同一文本仍只有一个文本对象。
- 在不同缩放比例下拖动普通图层，四条边线均能吸附。
- 橡皮擦拖动时有连续反馈，抬笔后撤销一次即可恢复。
- 前景色和背景色弹窗均能从当前画布取色，`Esc` 可取消。

## 验收标准

1. 六项用户报告的问题均有失败后转绿的自动化回归测试。
2. OpenShop 完整单元测试、汉化审计、仓库级构建和编码健康检查全部通过。
3. 工程版 `3000` 端口实测通过，测试不创建或保留 HstarA 画布数据。
4. 用户原有 `data/asset_library.json`、顶层 `static/*.html` 和 `assets/` 改动不进入本轮提交。
5. 当前功能分支保留，不合并 `main`，等待用户完成手工测试。
